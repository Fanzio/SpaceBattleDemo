# SpaceBattleDemo

Questa è una demo del gioco **SpaceBattle**, sviluppata in Unity 2D per scopi di apprendimento.  
Il giocatore controlla una navicella e deve eliminare le navicelle nemiche che appaiono sullo schermo per accumulare punti.

## 🎮 Caratteristiche principali

- Spawn di nemici normali in sequenza, con comportamenti semplici.
- Ogni livello termina con un **boss finale** da sconfiggere.
- Sistema di punteggio in tempo reale per ogni nemico distrutto.
- Controlli semplici: muovi la navicella e spara.
- Due livelli in stile arcade spaziale classico.

## 🖱️ Controlli PC

- Frecce direzionali o A/D → Muovere la navicella
- Click del mouse sinistro → Sparare
